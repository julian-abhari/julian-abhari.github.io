This website, play4change, is dedicated to preventing climate change through donations to various tree-planting charities. The website is still being developed; however, the core functionality is finished and the actual website is nearing completion. With play4change, users can upload any game or program they make, while other users play these games and earn ad revenue that gets donated to charities focussed on preventing climate change. I've been making this website since the start of my Senior year of high-school, and it was difficult to get started, as I had to work in an unfamiliar language. Sharing games and protecting the environment is something that is very dear to me, so I'm especially excited to launch this website whenever it gets completed.
